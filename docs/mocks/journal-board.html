日誌の予定ボード（予約台帳の形）

レストランボードの予約台帳と同じく、横が時間、縦が人。右の画面を指（マウス）で触ってください。見本の予定で、保存はしません。
  • 空いているマスを押す → その時間・その人で予定を足す
  • 予定を掴んで横へ → 時間を変える（15分ごとに止まる）
  • 予定を掴んで縦へ → 担当を替える
  • 予定の右の端を引く → 終わりの時刻を変える
  • 予定を押す → 済み・名前を直す・消す（元に戻せる）
  • 右上の 3時間／1日 で縮尺を切り替え（1日では細い予定は色だけ）。斜線は営業時間の外
  • 点線の帯は棚卸の記録（動かせない）。丸い形は終わりの無い「◯時までに」
  • 🔁 ルーティン：時刻があればボードに緑の点線で（1日に何回もなら回数分）。ずらすと「今日だけ／これから毎回」を訊く。時刻が無ければ「終日」に
  • ⏳ 進行中（何日もかかる）：ボードの上の段に、日数と期限を帯で。押すと経過を書く・済み
  • 📥 いつか（期限なし）：左下の箱にしまっておき、押してからマスを押すと、その時間に入る
