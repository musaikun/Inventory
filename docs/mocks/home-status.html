今日のやること・定期・進行中を、同じ形の進み具合の棒で1列に並べます。「気になる」と「時間の流れ」はなくしました。

札は3つだけ

  • 遅れ 時刻や締め切りを過ぎたもの（◯日遅れ）
  • 本日まで 締め切りが今日
  • 明日まで 締め切りが明日（前日に限って出す）

それ以外は札を出さず、右下に「本日 14:00」「11/30まで」とだけ書きます。

棒が表すもの

  • どれも済んだ割合（子タスク・チェック表の項目）。項目が無いものは 済み＝いっぱい／まだ＝空
  • 済んだものは緑の棒・取り消し線で下へ

並び

  • 遅れ → 本日まで → 明日まで → 時刻の順 → 締め切りの順 → 済み
