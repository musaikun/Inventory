作る入口は「＋ 追加」の1つだけ（日誌・ボード・ホームのやること、どこから押しても同じ画面）。 まず「何を」を書き、次にいつ（1回・いつか・進行中・繰り返す）を選ぶ。📋 項目を付けるを入れるとチェック表になる。 よく使うものは★ お気に入りにしておけば、次から押すだけ。作ったものは別の日にコピーできる。スタッフも作れる。画面の内容は見本。

今の作りからの変更

こと今変えた後サーバー
作る入口日誌の＋（やること）と、ルーティンの画面（🔁）が別「＋ 追加」の1つ。どこから押しても同じ画面要らない
チェック表ルーティンの中身として作る（管理者だけ）「📋 項目を付ける」で、1回でも繰り返すでも。スタッフも作れる作る権限を変える
いつか・進行中にチェック表付けられない付けられる（手順の✓）。後の版やることに項目を持たせる（migration）
別の日にコピー無いどの種類でも。日を何日でも選ぶ要らない（作るのと同じ）
★ お気に入り無い（見本のルーティンだけ）店で共有のひな形。押すと中身入りで追加ひな形の表を足す（migration）
