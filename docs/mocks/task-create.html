やることの作り方：入口を1つに、チェック表は種類の1つ、お気に入りと複製

作る入口は「＋ 追加」の1つだけ（日誌・ボード・ホームのやること、どこから押しても同じ画面）。 押したらまず種類を選ぶ（やること・チェック表・ルーティン・進行中・いつか）。次の画面はその種類に要る欄だけ。 よく使うものは★ お気に入りにしておけば、次から押すだけ。作ったものは別の日にコピーできる。スタッフも作れる。画面の内容は見本。

1「＋」→ まず種類を選ぶ → その種類に合う入力だけ

1-1 種類を選ぶ入力の画面に種類のボタンは置かない。最初にここで1つ選ぶと、次の画面はその種類に要る欄だけになる。下に ★ お気に入り（押すと中身入りで開く）

作る入口日誌の＋（やること）と、ルーティンの画面（🔁）が別。種類は入力の中で切り替え「＋ 追加」の1つ。最初に種類を選び、その種類の欄だけを出す要らない
チェック表ルーティンの中身として作る（管理者だけ）種類の1つ。1回でも繰り返すでも。スタッフも作れる作る権限を変える
いつか・進行中にチェック表付けられない付けられる（手順の✓）。後の版やることに項目を持たせる（migration）
別の日にコピー無いどの種類でも。日を何日でも選ぶ要らない（作るのと同じ）
★ お気に入り無い（見本のルーティンだけ）店で共有のひな形。押すと中身入りで追加ひな形の表を足す（migration）
