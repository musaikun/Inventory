発注：先に打って、何の数かは後で選ぶ

トグルをなくす。品目を開いたら、まず数字を打つ。打った数が「発注数」か「在庫」かは、下の2つのボタンで選ぶ。
発注数が分かる品目 → 打つ → 発注（2手）。分からない品目 → 数えた在庫を打つ → 在庫 → 推奨が入った発注の問い → 発注 / 発注なし。
在庫は強制しない（迷ったときの道具）。迷ったときだけ打たれた在庫は、そのまま分析にも使う。上の小さな札に「前回・推奨・理論在庫」を出し、在庫を打たずに決められる品目を増やす。

① 開いたところ打つ欄だけ。トグルは無い。何も打たずに「発注なし」も押せる
