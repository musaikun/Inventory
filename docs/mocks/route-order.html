今は順番を付けるまでに3段（ホイールの件数 → ⇅ 並び替え → ① タップ順で並べる）。見つけにくい。
案：振り分けの画面の上に「入れる｜順番」の切り替えを出し、品目の行に番号を出す。順番は番号を押していくだけ、直しは行の⋮⋮をドラッグ。
