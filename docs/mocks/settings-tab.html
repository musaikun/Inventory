設定タブ（以前の「管理」）

「各種設定」の中に隠れていたものを、設定タブに直接並べる。まとまりはお店 → 発注 → 品目 → この端末 → アカウント → サポート。 押すとその項目だけのシート（今の各種設定の中身）が開く。オン・オフだけのもの（通知・天気・匿名の利用状況）はその場で切り替える。
見えるものは権限で変える（スタッフ・発注の設定・品目の削除は持っている人だけ）。危ない操作（全品目の削除・アカウントの削除）はそれぞれのまとまりの一番下に赤で。
