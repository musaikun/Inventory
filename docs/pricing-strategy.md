# 料金・獲得戦略（未実装・要吟味メモ）

現機能の完成後に再吟味して実装する。ここは「決めたこと」と「決めた理由」の記録。

## 結論：リバーストライアル型（フル14日 → 無料の床）

- **有料は 2,980円/月 の1本のみ**。機能別の複数tierは作らない（複雑さを生むため）。
- **サブスク一択**。買い切りは不採用（クラウド同期・D1・ストレージの継続コストと赤字構造になるため）。
- **登録から14日はフル機能**（棚卸・発注・ルーム・分析すべて）。
  - トライアル中はインポート無しでも棚卸で在庫品目を作れる → 品目マスタを育てられる。
- **14日後に未課金なら「無料の床」に降格**：入出庫＋品目マスタのみ使える状態で継続。
- 判定は `isPro`（課金）を `hasFullAccess = 課金 or トライアル中` に抽象化する方向。

## なぜこの形か（3つの狙いを1プランで満たす）

| 狙い | この設計での効き方 |
|---|---|
| ダウンロード数 | 14日後に切り捨てず床に着地 → アプリが消されず端末に残る（ランキング・維持率） |
| レビュー | 使い続ける人が残る＋全員が一度フル機能の感動を経験 |
| こぼれた層 | ZAICO難民（無料/500円希望の個人・零細）が床に着地 |
| 課金転換 | 飲食店はフルを14日体験 → 棚卸・ルームが無いと回らないと痛感 → 課金 |

- セグメントが自然に分離：飲食店＝課金／個人・零細＝無料の床。
- 「欲張り」ではない。有料1本＋無料床1枚で、tierは刻んでいない。

## 市場ポジション（対 ZAICO）

- ZAICO：スターター 11,400円／ベーシック 63,000円。無料をやめ有料のみに。
- 本アプリ 2,980円フラット＝ ZAICO の 1/4〜1/20。「ZAICOは高い、でも機能は要る」層に刺さる。
- 入出庫は ZAICO の芯（現物にQR→スキャン→現在庫更新）から着想。その"おいしい部分だけ"を軽く無料で出すのがwedge。

## 成否の9割：降格の体験設計（最重要）

雑にやると「最高だったのに急にロックされた★1」を生み、狙うレビューが逆噴射する。

### やってはいけない
- トライアル中に作った棚卸データ・発注履歴を削除／不可視化する（データ喪失感＝即★1）。

### やるべき
1. **作ったデータは消さない**。棚卸スナップショット・発注履歴は閲覧・エクスポート可のまま（新規作成のみ不可）。
2. **品目マスタは丸ごと床に引き継ぐ**。トライアルで棚卸しながら育てた品目 → 無料の床で入出庫に使い続ける（完璧なオンランプ）。床でも品目追加は許可。
3. **降格を"喪失"でなく"贈り物"としてフレーミング**：
   - ✅「14日間ありがとうございました。これからも入出庫はずっと無料で使えます」
   - ❌「無料期間が終了しました。棚卸を使うにはアップグレードを」
4. **レビュー依頼は感動の瞬間（7〜10日目・初回棚卸完了や発注予測的中の直後）**に出す。降格後には出さない。

## 割り切るリスク

- 無料の床があると課金の緊急性は少し下がる。ただし床＝入出庫のみで飲食店の本業（月次棚卸・多人数）は満たせないため本命層は課金する。
- 個人層は元々2,980円非課金層 → 床に残って口コミ源になれば十分。転換率低下より DL＋レビュー＋口コミの価値が上回る賭け。
