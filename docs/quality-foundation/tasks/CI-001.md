## Node バージョン不整合 — 統合項目

- 原因:
  - CIのNode 20.20.2では`node:sqlite`を利用できず、`worker/test/pushHandler.test.js`のimportで失敗した。
  - `@zxing/library@0.22.0`はNode >=24を宣言しており、Node 20/22ではengine警告になる。
  - `worker/package-lock.json`の`pdfjs-dist@5.7.284`もNode >=22.13または>=24を要求する。
- ローカル対応(2026-08-02 / Codex): `develop-preview.yml`と`pro-review.yml`をNode 24へ更新した。
- 検証(Node 22.14.0): Worker 15 files / 196 tests、分離後App 54 files / 467 tests、
  App production build（444 modules）が成功。`git diff --check`も成功した。
- 残り: commit / push後にGitHub Actionsを再実行し、Node 24での全step成功とdevelop preview更新を確認する。
