# DEP-001 — 本番依存の high 脆弱性を解消または隔離

- 状態の正本は [`../task-list.md`](../task-list.md)
- **統合**: `postcss` は新規IDを作らず本タスクで扱う（元の題名は「`xlsx` の high 脆弱性を解消または隔離」）。

- 元の根拠（2026-07-25 監査）: `npm audit --omit=dev` で prototype pollution / ReDoS。現行版に自動修正版なし。
  → 2026-08-01 に再測定し、`postcss` の high が別途あること、そちらには修正版があることを確認した（下記）。

## 現状（`cd app && npm audit --omit=dev` / 2026-08-01 実行）

**production 依存に high 2件。**

| package | 版 | 深刻度 | 内容 | 修正版 |
|---|---|---|---|---|
| `postcss` | `<=8.5.17` | high | Path Traversal in Previous Source Map Auto-Loading（`sourceMappingURL` 経由で任意の `.map` ファイルが露出）— [GHSA-r28c-9q8g-f849](https://github.com/advisories/GHSA-r28c-9q8g-f849) | **あり**（`npm audit fix` で解消可能） |
| `xlsx` | `*` | high | Prototype Pollution（[GHSA-4r6h-8v6p-xvw6](https://github.com/advisories/GHSA-4r6h-8v6p-xvw6)）／ ReDoS（[GHSA-5pgg-2g8v-p4x9](https://github.com/advisories/GHSA-5pgg-2g8v-p4x9)） | **なし** |

対応の性質が違うため分けて扱う。

- **postcss**: 自動修正版が存在するため、`npm audit fix` 後に build と test を通せば閉じられる。
  ビルド時のみ使用されるかランタイムに載るかを確認し、`app/dist` への影響を検証する。
  スプリント凍結の「脆弱性解消に不可欠な依存更新は例外」に該当する。
- **xlsx**: 修正版がなく、**ユーザー提供ファイルを処理する経路**（CSV/Excel取込）で使われるため、
  library移行・機能隔離・明示的リスク受容のいずれかを選ぶ判断が要る。

## 関連

- `CI-001` の Node バージョン不整合（`@zxing/library` が Node >=24 を宣言）と同時に決めると、
  依存まわりの差分が一度で済む。

## 完了条件

- 代替 library 移行、機能隔離、または明示的リスク受容を決める。
- ユーザー提供ファイルの size・行列数・処理時間を制限する。
- 実ファイル回帰テストを維持する。
- `postcss` は修正版へ更新し、build と App テストで回帰がないことを確認する。
