# DEP-001 — 本番依存の high 脆弱性を解消または隔離

- 状態の正本は [`../task-list.md`](../task-list.md)
- **統合**: `postcss` は新規IDを作らず本タスクで扱う（元の題名は「`xlsx` の high 脆弱性を解消または隔離」）。

- 元の根拠（2026-07-25 監査）: `npm audit --omit=dev` で prototype pollution / ReDoS。現行版に自動修正版なし。
  → 2026-08-01 に再測定し、`postcss` の high が別途あること、そちらには修正版があることを確認した（下記）。

## 監査時点（`cd app && npm audit --omit=dev` / 2026-08-01 実行）

**production 依存に high 2件。**

| package | 版 | 深刻度 | 内容 | 修正版 |
|---|---|---|---|---|
| `postcss` | `<=8.5.17` | high | Path Traversal in Previous Source Map Auto-Loading（`sourceMappingURL` 経由で任意の `.map` ファイルが露出）— [GHSA-r28c-9q8g-f849](https://github.com/advisories/GHSA-r28c-9q8g-f849) | **あり**（`npm audit fix` で解消可能） |
| `xlsx` | `<0.20.2` | high | Prototype Pollution（[GHSA-4r6h-8v6p-xvw6](https://github.com/advisories/GHSA-4r6h-8v6p-xvw6)）／ ReDoS（[GHSA-5pgg-2g8v-p4x9](https://github.com/advisories/GHSA-5pgg-2g8v-p4x9)） | npm registryにはなし。SheetJS公式CDNに修正版あり |

対応の性質が違うため分けて扱う。

- **postcss**: 自動修正版が存在するため、`npm audit fix` 後に build と test を通せば閉じられる。
  ビルド時のみ使用されるかランタイムに載るかを確認し、`app/dist` への影響を検証する。
  スプリント凍結の「脆弱性解消に不可欠な依存更新は例外」に該当する。
- **xlsx**: npm registryの最終版`0.18.5`には修正版がない。一方、SheetJS公式文書は公式CDNの
  `0.20.3`を案内しているため、**ユーザー提供ファイルを処理する経路**はその修正版へ移行する。

## 対応結果（2026-08-02 / Codex）

- `postcss`を`8.5.15`から`8.5.25`へ更新した。
- `xlsx`をnpm registryの`0.18.5`から、[SheetJS公式手順](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)が
  案内する公式CDN tarball `0.20.3`へ更新した。package-lockのintegrityで取得内容を固定する。
- 公開UIからのExcel解析をWeb Workerへ隔離し、8秒を超えたWorkerはterminateする。
- 解析前後の上限を、5 MiB、20シート、各5,000行・100列、合計100,000セルに固定した。
  SheetJSの`sheetRows`と`!fullref`を使用し、元の行範囲が上限超過なら取り込まない。
- `.xlsx` / `.xls`の日本語データ、行・列・シート上限、Worker timeoutを回帰testで固定した。
- `npm audit --omit=dev`: **0 vulnerabilities**。通常の`npm audit`にはbuild/test用依存の
  6 high / 3 moderate / 1 lowが残るが、本タスクのproduction依存には含まれない。
- 検証: App 58 files / 498 tests、production build成功。Worker asset
  `spreadsheetImport.worker-*.js`が独立生成され、PWA precacheへ含まれることを確認した。
  `git diff --check`成功（改行形式warningのみ）。
- 未実施: commit、push、deploy、実機でのファイル選択確認。
