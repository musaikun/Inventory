# UI-005 — Riveを公開面で動かす前提（CSPとPWAキャッシュ）

## 範囲

- 着手日: 2026-09-09。Userの「Riveを入れた。動きのあるアイコン・操作でアプリの質を高める」を受け、
  **公開面（Cloudflare Pages）でRiveが動く前提**だけを整える。
- `UI-004`（試験環境・素材制作・担当Codex）とは分ける。`.riv`素材、演出の内容、製品画面への
  組み込みは触らない。UI-004が「今回は公開headerを変更しない」として残した2点を引き取る。
- 変更するのは配信header（CSP）とPWAのキャッシュ方針のみ。API、DB、認可、業務データ、
  同期、app versionは変更しない。画面の見た目も変えない。

## 背景（なぜ素材より先か）

- 公開面のCSPは `script-src 'self'`。Chromium系はChrome 97以降、WASMのコンパイル・実体化に
  `'wasm-unsafe-eval'`（または `'unsafe-eval'`）を要求する。**vite devは `public/_headers` を
  適用しない**ため、素材が完成してもローカルでは普通に動き、Pagesへ出した瞬間に演出だけが
  落ちる——という気づきにくい形で出る。素材の出来と切り分けるためにも先に通しておく。
- `.wasm`（約2MB）は `globPatterns` の対象外＝プリキャッシュに載らず、runtimeCachingも無いので
  Service Workerが面倒を見ない。厨房・地下・電波の悪い店で毎回失敗する。
- 一方でランタイムJS（約195KB）をプリキャッシュに載せると、演出を一度も見ない人の
  初回インストールにも乗る。載せずに「初回だけ取得して以後キャッシュ」へ寄せる。

## 完了条件

- 公開面のCSPでWASMの実体化が通る。許可は `'wasm-unsafe-eval'` に限定し、
  JSの `eval` を開ける `'unsafe-eval'` は入れない。
- Riveのランタイム（JS・WASM）と `.riv` が、初回だけネットワーク・以後キャッシュで動く。
- 演出を一度も見ない人の初回インストール量を増やさない。
- 実機（Android Chrome / iOS Safari）での確認手順を残す。

## 実装

- `app/public/_headers`: `script-src 'self'` → `script-src 'self' 'wasm-unsafe-eval'`。
  他のdirectiveは変更なし。`connect-src` は既に `'self'` を含むため、同一originからの
  WASM取得に追加は要らない。`'unsafe-eval'` は入れない（JSのevalは塞いだまま）。
- `app/vite.config.js`:
  - `globIgnores: ['**/riveRuntime-*.js']` … ランタイムchunkをプリキャッシュから外す。
    ファイル名は `src/utils/riveRuntime.js` に由来。改名したらここも直す
    （外れてもプリキャッシュに載るだけで壊れない）。
  - `runtimeCaching` に `rive-runtime`（CacheFirst・1年・maxEntries 8・statuses [0,200]）を追加。
    対象は `riveRuntime-*.js` / `*.wasm` / `*.riv`。ハッシュ付きファイル名なので、更新は
    別URLとして落ち、古い版は maxEntries を超えた時点で捨てる。

## 組み込みの順番（2026-09-09 User判断）

製品画面への**最初の組み込みは、`.riv`が1つ揃うまで待つ**。素材が無いまま入れ物だけ先に作ると、
実物の寸法・状態・鳴らし方に合わず作り直しになるため。`UI-004`のホイールが `.riv` として
出てきた時点で、その1本で組み込みの型（下の受け渡し条件）を固める。

### 素材を受け取るときの条件（組み込み側から）

- **落ちても画面が使えること**: Riveが読めない・reduced motion・WASM未対応でも、いまの静的な
  表示で操作が完結する形にする。演出が操作そのものを担わない（`RiveCanvas`のエラー文言を
  そのまま製品画面に出さず、静的表示へ退く）。
- **名前を決めて渡す**: artboard名・state machine名・入力（trigger/boolean/number）名を固定して
  もらう。コード側はこの名前で鳴らすため、後から変わると差し替えが効かない。
- **寸法**: 375px幅の実機で置く場所の実寸（例: 56pxカード内・全画面の帯）を先に決め、
  `Fit.contain` で破綻しない縦横比にしてもらう。文字は焼き込まない（多言語・改名で腐るため）。
