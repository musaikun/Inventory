## 範囲

- 期間: 2026-09-23〜2026-09-25（Userの明示依頼によるUI・機能追加）
- 対象 commit: `develop` の v0.113.0 まで（詳細は [session-log](../session-log.md) の同期間）

- Web release gate（WEB-01〜10）には含めない。gate へ入れるかは PM 判断。

## 準備

- 端末 A（ホスト）: スマホ（iPhone SE2 相当 375px と Android Chrome の両方が望ましい）
- 端末 B（ゲスト）: 別端末またはシークレットウィンドウ（🔁 の項目だけ）
- 確認先: `https://develop.inventory-app-c40.pages.dev`（preview は本番 Worker を参照）
- 取込用に「小計」「【区分】」行とファイル内の重複行を含む品目CSVを1つ用意
- 棚卸履歴が3回以上ある店舗（未計測の確認用）

凡例: 🖐=手動 / 🔁=複数端末（**Worker 再デプロイ後**に確認。それまではゲストへ届かないのが正しい）

## 1. データ管理トップ 🖐

- [ ] 「取り込む／書き出す」「整える・確認」の各カードが 375px で崩れない
- [ ] 「品目の点検」カードに要確認の件数が出る（0件のときは灰色）
- [ ] 各カードの「?」で説明が開閉する

## 2. 設定済み品目一覧 🖐

- [ ] 上部の件数5枚（全体／表示中／非表示・うち自動／ジャンルなし／取込で除外）が正しい
- [ ] チップ: ジャンル → 「設定済みグループ」の点線枠（作ったグループ。無ければ枠ごと出ない）→ 非表示設定品目 → 非表示にした順
- [ ] 左右スワイプでチップが隣へ移り、端で止まる。縦スクロールではチップが変わらない
- [ ] 非表示設定品目がジャンル別アコーディオンで出る。非表示にした順は最後に隠したものが先頭で時刻付き
- [ ] 表は確認専用（数量・発注点などの入力欄が無い）
- [ ] 「取込で除外」を押すと行名と理由が開く。「品目にする」で追加され一覧から消える／登録済みは「登録済み」
- [ ] 戻る（端末の戻る操作を含む）で一覧が閉じ、データ管理へ戻る

## 3. 品目の点検 🖐

- [ ] 入数・単位・単価・ジャンルが空の品目と、直近3回未計測の品目が出る（非表示は出ない）
- [ ] チップで種類ごとに絞れる（0件のチップは押せない）
- [ ] 行を開いて埋めて保存 → 空欄が無くなれば一覧から消える。ソフトキーボードで入力欄が隠れない
- [ ] 未計測の行で「最後に数えたのは M/D」と「非表示にする」。非表示にした品目は設定済み品目一覧から戻せる
- [ ] 保存・非表示のあと、再読み込みしても反映が残る（D1 保存）

## 4. 振り分け画面（品目リスト整理 → グループ化・並び替え）🖐

- [ ] 開いたホイールの高さがカード3枚分（中央＋前後1枚）
- [ ] 分類先が0件でも、品目一覧に触れると帯へ畳まれ「＋ 分類先を追加」が残る。ホイールに触れると開く
- [ ] 「変える ▾」が帯に出ない。開閉のアニメーションが以前より速い（350ms）
- [ ] 1段目は検索と「未振り分けのみ」、2段目に「前回入力のみ・未計測のみ・新規のみ・非表示のみ」が折り返さず並ぶ（360px でも）
- [ ] 一覧の上に「左にスワイプすると、非表示にします」の案内。一度非表示にすると消える
- [ ] 「非表示のみ」チップ（非表示の品目があるときだけ）。他の「〜のみ」と排他
- [ ] 非表示のみで左スワイプ → 青い「表示に戻す」。引き切ると即戻り取り消しバーが出る。浅く引いて押すと確認
- [ ] 非表示のみでタップ・長押ししても振り分けない（タップで案内）
- [ ] 通常表示の左スワイプは従来どおり赤の「非表示」

## 5. 検索・数量入力の非表示マーク 🖐

- [ ] 棚卸で非表示中の品目を検索すると、候補に赤い「非表示」が付く
- [ ] その品目の数量入力画面にも「非表示」が付く

## 6. 仕入れ → 在庫タブ「🎯 発注基準を設定」🖐

- [ ] 初回は3問（届くまで／余裕／何日分。何日分は発注間隔からの既定値入り、ジャンル別に上書き可）
- [ ] 保存後、棚卸1回分しか無い品目にも「仮」の発注点・補充目標と式が出る。在庫の記録が無い品目は「未設定」
- [ ] 数字を入れると「手動」、「自動に戻す」で解除。「仮の値を使わない」で従来の挙動に戻る
- [ ] 発注の数量入力で、推奨が入数で切り上がる。余りが入数の半分以上なら「切り上げで +N 余ります」
- [ ] 補充目標が仮のとき「（仮）」が付く

## 7. 複数端末 🔁（Worker 再デプロイ後）

- [ ] ホストが保存した発注基準の仮定がゲストにも反映される
- [ ] ホストの取込で残った「取込で除外」がゲストの設定済み品目一覧にも出る
- [ ] ホストが品目の点検・振り分け画面で非表示／表示に戻した結果がゲストの一覧に反映される
