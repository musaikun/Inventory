# 2026-11-09 — 網羅的な触診（ローカル Worker＋実ブラウザ）

- version: 0.198.3 → **0.198.4**（docsのみ）
- 対象: v0.198.2 相当。`e2e/scripts/start-worker.sh`（Miniflare・まっさらなD1）＋`start-app.sh`、Playwright で Pixel 7 / 320px

User: アプリを網羅的に触って、問題点・ユーザビリティ・予想外の使い方で壊れないかを知りたい

## 不具合
1. 棚卸の検索欄に打った文字が音声の分解（`useVoice.js` parseText）を通り、名前の中の数字を数量に、単位の文字（g・L・kg・ml・個…）を位置に関係なく1つ取り、空白を全部消す。例: 「<img src=x …(1)>」→「<imsrc=xonerror=alert()>」。「コーラ500ml」→ 名前コーラ・数量500。英字の品目名（LATTE など）が欠ける
2. 同じ名前の品目があっても、候補の一番上（点線の主ボタン）が「＋『トマト』を新しく登録」。同名の品目を作れてしまう
3. 毎週の繰り返しは、追加の画面で選んだ日付（例 11/21）ではなく今日を始まりに保存する（曜日は選んだ日付の曜日になる）
4. 予定ボード: 数分の記録（棚卸 14:2x〜14:2x）が細い帯になり、文字が縦に積まれて読めない。名前の列で「オーナー」が「オーナ／ー」と折れる
5. 名前が長いと完了の通知（トースト）が画面の上半分を覆う

## 文言・見た目
- ログイン画面「セッション履歴を管理できます」、登録完了「セッション一覧へ」、ランディング「棚卸作業を開始してください」が棚卸だけのアプリの頃の言葉
- 空のホームで「気になるものはありません」と「今日のやることはありません」が同時に出る
- ホームの下のメニューの赤い数字（2・新着）が何の数か分からない
- 発注を始めても「pantopsの使い方」（棚卸の説明）が出る
- 設定の「ℹ️ アプリ情報」だけ絵文字のアイコン
- 320px: 「品目リスト整理」が「品目リスト整／理」、カレンダーの繰り返しの札が「曜…」
- スタッフ招待: アルバイトと社員の説明文が同じ。オーナーの暗証番号は4桁、スタッフは6桁

## 仕様として確認したいこと
- オーナーで別の端末にログインすると、前の端末はログアウトされる（authHandler: 単一ホスト。棚卸の整合のため）。店の固定タブレット＋自分のスマホの使い方ができない

## 壊れなかったこと（確認済み）
- 空・空白だけの名前は追加できない。名前は200字で止まる。追加ボタンの2度押しで重複しない。＋の連打でシートは1枚
- タブ30回の高速切り替え、入力中の戻る（確認が出る）、戻るで 日→月→ホーム
- オフライン: 帯で知らせ、端末に保存、再読み込みしても使え、戻ると別の端末に届く
- 棚卸の再読み込みで続きから。数が入っている品目は「上書き／足す」を訊く
- 320px でどのタブも横にはみ出さない
- スタッフ招待→参加申請→承認→自動ログイン。アルバイトのトークンでスタッフ一覧・品目の設定変更はサーバーが403
- 入力した名前はどこでもHTMLとして実行されない（v-html はチャットだけ・先にエスケープ）
