# 2026-11-28 — 別のアプリから戻ると入力途中の業務の追加が消える

User報告: 業務の追加を開いて文字を入れたあと、別のアプリを開いて戻ると、入力中のものが消える

- 原因: ホーム（`SessionListPage.vue`）はアプリに戻ってくる（visibilitychange）たびに棚卸の一覧を読み直す。
  そのとき `loading` を true にしていたため、`v-if="!loading && …"` のタブ（ホーム・業務・レポート・設定）が
  いったん消えて作り直され、中で開いていたシート（業務の追加など）と入力が消えていた
- 変更: `useSessionLauncher.load({ quiet })` を足し、戻ってきたときの読み直しは読み込み中にしない。
  裏の読み直しの失敗（電波が弱い等）は画面に出さず、前の一覧のまま
- 残件: OS がアプリそのものを閉じて読み込み直した場合（メモリ不足など）は、今も入力は残らない。必要なら下書きを端末に残す
