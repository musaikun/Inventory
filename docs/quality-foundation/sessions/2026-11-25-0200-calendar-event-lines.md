# 2026-11-25 月のカレンダーのイベントの線（v0.217.0）

- User: カレンダーの「+n」は意味が分からないのでやめる。週の途中から始まるイベントが、その週に出ず翌週の頭から出るように見える。いつから・いつまでを一目で。10件重なったら？ → モック（https://claude.ai/artifact/6K3ZSPXRnvBo6zQCUwQiSh・`docs/mocks/calendar-event-lines.html`）で「これで実装」
- 原因: 1週に2本まで・前の週から続く線を先に取っていたため、週の途中から始まるものが押し出されていた
- 変更（`JournalMonth.vue`）:
  - 始まりの日は塗った名札、続きの週は「‹ …名前」の点線の札。終わりの日は止め線＋「〜m/d」（2日以上）。次の週へ続くなら「›」
  - イベントは上に4段まで、進行中はその下に3段まで（混ぜない）。週の高さは線の数で伸び、月は縦スクロール（`minmax(min-content, 1fr)`）
  - 段は その週に始まる → 終わる → 続いているだけ の順に、空いている一番上へ（終わった段は次が使う）
  - 入りきらなければ最後の段に「ほか〇件（のイベント）」を件数が変わる日で区切って出す。押すとその期間の一覧（選ぶとそのイベント・進行中を開く）
  - v0.216.0 の日ごとの「+n」は廃止
