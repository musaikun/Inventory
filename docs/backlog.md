# バックログ

## 🔴 高優先度

### 店舗コード方式の外部データ永続化
- localStorage 依存の解消（端末変更・担当者交代に対応）
- Cloudflare D1 に品目リスト・棚卸履歴を保存
- 認証済み端末なら任意端末から同じデータにアクセス可能

### PDF処理の軽量化（iPhone SE2 で処理が完了しない）
- 現状: pdfjs-dist をクライアント側で全ページ処理
- 対策案（優先順）:
  1. Cloudflare Worker でサーバー側テキスト抽出（スマホCPU負荷ゼロ）
  2. PDF廃止・Excel統一（運用対応）
- 遅延読み込み・進捗表示・40秒タイムアウトは実装済み
