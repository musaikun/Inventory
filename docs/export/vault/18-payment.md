# 18 決済

スナップショット: 2026-07-15 / v0.48
状態: **未実装**（Stripe サンドボックス検証待ち）

## 決定事項
- **Web決済 = Stripe 主体**（手数料・全デバイス対応）
- **Google Play 内では決済しない**: リーダーアプリモデル（価格・決済導線を出さない／契約済みログイン入口のみ）→ Play課金15-30%とポリシー審査を回避
- カード情報は Stripe が直接処理（自サービスに保存しない・PCI DSS 対象外化）
