## 運用ルール
1. 発見したら下の表に1行追加（再現手順は詳細欄 or 子ページ）
2. 修正セッションに渡す時はこの行のIDを伝える
3. 修正完了 → 状態を✅に・**共通チェックリストに「この事故を防げた項目」を追加**（事故駆動で育てる）
4. 重大なもの（データ消失・セキュリティ）は `docs/security-review.md` にも台帳化
