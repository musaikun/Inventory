# 02 機能一覧

スナップショット: 2026-07-15 / v0.48（正: `docs/project-status.md`）

## 実装済み ✅
### 入力・取込
- 音声入力＋品目別辞書補正／テキスト／バーコード
- CSV・Excel・PDF 取込（PDF列マッピングのレシピ保存）／テキスト貼り付けパース
- 同名品目の統合（完全一致）／ゲスト品目追加→ホスト承認

### 棚卸・同期
- 複数端末リアルタイム同期・競合解決（3秒以内同時入力→3択バナー）
- オフライン入力→再接続マージ／接続バナー・保存失敗の自動再送
- 招待リンク（ルーム限定URL・完了後3日間の結果閲覧）／チャット／変更履歴

### 発注・入出庫
- 発注セッション（オレンジ）・適正在庫の曜日別学習・推奨発注数
- **発注数のリアルタイム同期**（DO の orders チャネル・品目ごとに「発注N（誰が）」チップ）※2026-07-15取込
- **入出庫の未記録ドラフト保持**（入力・日付・メモ・発注紐付けを端末保持、ホームカードに「未記録N」バッジ・破棄ボタン）※同上
- **発注→入庫の未反映可視化**（未反映の発注バッジ＋入庫タブの反映プロンプト。反映は手動＝分納・欠品を人が確定）※2026-07-17取込
- 入出庫（グリーン・MovementPage・スワイプ切替）／発注→入庫ワンタップ取込
- 理論在庫（棚卸残高+入出庫）とズレ検出

### 分析・管理
- 在庫分析ダッシュボード（在庫金額・前回差・ABC・曜日・信頼度）
- 履歴カレンダー（棚卸/発注/入出庫統合・種別フィルタ・金額概算）
- 分類軸（最大2軸・複数所属・ドラッグ並び替え・再インポート維持）

### 基盤
- D1永続化／認証（店舗コード+PIN）／監査ログ／プッシュ通知
- 端末間アカウント設定同期／無料・PROプラン骨組み＋サーバー側プラン土台
- TWA対応（アプリ版は価格非表示）／空リスト・練習モード
