# 11 セキュリティ

スナップショット: 2026-07-15 / v0.48（正: `docs/security-review.md`・生きた台帳）

## 対応済み ✅
| ID | 内容 |
|---|---|
| S-01 | ログイン総当たり: 店舗単位 5回/15分ブロック |
| S-05 | IP単位レート制限 30回/15分（login/probe独立） |
| S-02 | データ系APIのソフト認証（PIN設定店舗はBearer必須） |
| S-03 | ペイロード上限 約1MB |

| S-A | ホスト乗っ取り: 保護店舗のホスト権限再発行にD1認証トークン必須 |
| S-10 | クロスアカウント漏洩: `_data_owner` マーカーで切替時ローカル全消去 |

## 設計上のスタンス（記録）
- レート制限は**フェイルオープン**（D1障害でもログインを止めない=可用性優先）
- ホスト認証はWSのjoinメッセージにトークン同梱（ブラウザWSはヘッダ不可・WSS暗号化前提）
- D1障害時のホスト復旧はフェイルオープン（レガシー扱い）

## 運用ルール
- 新エンドポイント=認証ゲート内＋レート制限＋api-design登録（共通チェックリスト）
- 事故が起きたら security-review.md に台帳追記＋チェックリストに再発防止項目を追加
