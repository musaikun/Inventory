# 10 OCR

スナップショット: 2026-07-15 / v0.48
状態: **未実装・未着手**（現状はテキスト埋め込みPDFの抽出のみ → [09 PDF解析](09-PDF解析.md)）

## 想定ユースケース（アイデア段階）
- スキャン・写真のPDF/画像からの品目リスト取込（現状は取込不可）
- 納品書・請求書の写真 → 入庫記録の自動起票（フェーズ4「仕入先連携」への布石）
- 手書き棚札・値札の読み取り

## 実装時の選択肢（着手時に評価）
| 方式 | 特徴 |
|---|---|
| Cloudflare Workers AI（画像→テキスト系モデル） | 同一プラットフォーム・従量課金 |
| 外部 OCR API（Google Vision 等） | 精度高・データ外部送信（法務・ポリシー確認要） |
| クライアント側（Tesseract.js 等） | データが端末を出ない・低精度・端末負荷 |

## 判断基準（着手条件）
- 「スキャンPDFが取り込めない」問い合わせ・失注の実数（→ [27 サポート・FAQ](27-サポートFAQ.md) に記録）
- 精度が低いOCRは誤った品目マスタを作り、後段の全分析を汚す。**信頼度ゲート＋人の確認**を必須に
