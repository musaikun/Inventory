## 運用ルール
- 各ノート冒頭の「スナップショット」はリポジトリ docs から生成した定点コピー（編集自由）。
- 「記録すること」節が日々の追記場所。リポジトリ側の意思決定は `docs/` が正、
  個人の思考・下書き・営業メモはこちら側が正、と分担する。
- 大きな節目（課金開始・Play公開）で PM セッションに再生成を依頼する。
