# 06 SaaS設計

スナップショット: 2026-07-15 / v0.48（正: `docs/pricing-strategy.md`・`docs/enterprise-design.md`）

## プランモデル（リバーストライアル）
```
登録 → 14日フル機能（棚卸・発注・ルーム・分析すべて）
     → 課金(2,980円/月) or 無料の床（入出庫＋品目マスタのみ）へ降格
```
- 判定は `hasFullAccess = 課金 or トライアル中` に抽象化する方針
- 降格しても**データは消さない**（閲覧・エクスポート可、新規作成のみ不可）
- 品目マスタは床に丸ごと引き継ぐ（トライアルで育てた資産を持ち越し）

## サーバー側プラン管理（E0/C-01）
- ✅ 土台: `stores.plan` 列＋`created_at` 起点の14日トライアル導出（`entitlements.js`）。`/auth/*`・`GET /store/:code` が `{ plan, isPro, inTrial, trialEndsAt }` を返す（サーバーが正）
- ⬜ 残: 無料の床の具体ゲート確定・`LIMITS_DISABLED`/`tanaoro_is_pro` の撤去（現状**本番全員PRO**）
- ⚠️ 前提: 入出庫のD1同期（床の主役データが localStorage 専用のままでは戦略が崩れる）

## 無料プラン制限（骨組み）
150品目 / 履歴直近1回 / 同期3台 / 取込は無料（体験は触らせ、履歴・規模で課金転換）

## 企業導入（フェーズ2・設計のみ）
- 組織 > 店舗の階層・本部ビュー・多店舗集計（`enterprise-design.md`）
- 着手条件: 最初の企業引き合い後に実要望を聞いてから（E1以降）
- B2B契約形態（席数/店舗数・請求書払い）は未設計
