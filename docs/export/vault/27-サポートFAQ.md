## 予想される最頻問い合わせ（先回りで準備）
| 問い合わせ | 現状の答え | 恒久対策 |
|---|---|---|
| PINを忘れた・入れない | **復旧手段なし**（連絡先も保持していない） | リカバリーコード or メール/OAuth（C-07・課金前に） |
| 機種変更でデータが消えた | 在庫・履歴・発注はD1にありログインで復元。**入出庫は消える** | 入出庫D1同期（Wave 2.5） |
| ゲストが参加できない | 招待URLはその回限り（新セッションで失効）。ホストから再共有 | FAQ化 |
| 音声がうまく認識しない | 辞書（エイリアス）に登録すると補正される | ヘルプ整備 |
| 障害？動かない | 告知チャネルなし | ステータスページ（[24 運用](24-運用障害対応.md)） |
| 解約したい・データを消したい | **削除フローなし** | 退会機能（Wave 2.5・Play要件） |
