# 17 マネタイズ

スナップショット: 2026-07-15 / v0.48（正: `docs/pricing-strategy.md`）
状態: **戦略確定・実装保留**（現機能の完成後に再吟味して実装）

## 決定事項
- **有料は 2,980円/月 の1本のみ**。複数tierは作らない（複雑さ回避）
- **サブスク一択**（買い切りはクラウド継続コストと赤字構造のため不採用）
- **リバーストライアル**: 登録14日フル → 未課金は「無料の床」（入出庫＋品目マスタ）へ降格
- 降格の体験設計が成否の9割: データは消さない・床でも品目追加可・「贈り物」フレーミング

## 割り切ったリスク（記録）
- 床があると課金の緊急性は下がる → 床=入出庫のみで飲食店の本業（月次棚卸・多人数）は満たせないため本命層は課金する、という賭け
- 個人層は元々非課金層 → DL・レビュー・口コミの価値が転換率低下を上回ると判断
