# 26 用語集 ★追加分類

スナップショット: 2026-07-15

| 用語 | 意味 |
|---|---|
| タナオロ | 本サービス名（棚卸の高速化アプリ） |
| shopCode / 店舗コード | テナントキー。DOルームID＝D1分離キーと統一 |
| PIN | 店舗の暗証番号（現4桁・PBKDF2ハッシュ） |
| ホスト / ゲスト | ルーム主催端末（全権・原価閲覧可）と参加端末（入力のみ） |
| hostToken | DOが発行するホスト認証トークン（再接続で検証） |
| ルーム | 1店舗の同期空間（Durable Object）。1店舗=1DO |
| セッション | 棚卸/発注の1回分。sessionId で新旧区別。type=stock/order |
| ルーム限定URL | `?store=CODE&s=セッションID`。その回限りの招待リンク（完了後3日は結果閲覧） |
| auditLog | 操作記録（誰が・いつ・何を・何個）。DO内200件→完了時に履歴へ |
| 軸（axis） | 品目の分類軸（場所・仕入先など最大2軸・ユーザー定義・複数所属可） |
| ジャンル | 品目のカテゴリ（軸とは別の既存分類） |
| 入出庫（movements） | 入庫/出庫のフロー記録（v0.48。現状localStorage専用） |
| 理論在庫 | 直近棚卸残高＋その後の入出庫から導出する推定現在庫 |
| パー（par） | 発注点・定数在庫（未実装。手動登録→算出の2段階予定） |
| 営業日 | 深夜またぎを前日に寄せる業務日付（切替既定5時） |
| 信頼度 | 分析の確からしさ採点。「甘い数字を出さない」ためのゲート |
| リバーストライアル | フル14日→無料の床へ降格する料金モデル |
| 無料の床 | 降格後も使える範囲（入出庫＋品目マスタ）。2,980円/月が有料の1本 |
| entitlements | サーバー側のプラン判定（plan/isPro/inTrial/trialEndsAt） |
| LIMITS_DISABLED | プラン制限の一時全解除フラグ（本番焼き込み中・課金開始時に撤去） |
| ソフト認証 | PIN設定店舗のみBearer必須、レガシー店舗は素通しの後方互換認可 |
| フェイルオープン | 障害時に「許可側」へ倒す設計（可用性優先。レート制限等で採用） |
| D1 / DO / R2 | Cloudflareの SQLite DB / ステートフル実行単位 / オブジェクトストレージ |
| TWA | Trusted Web Activity。PWAをPlayストアアプリとして配布 |
| リーダーアプリモデル | アプリ内に価格・決済導線を置かない Play ポリシー対応 |
| PWA | ホーム画面追加・オフライン対応のWebアプリ |
| Wave | ロードマップの実行単位（0→1→2→2.5→3） |
| DoD | Definition of Done。新機能の共通チェックリスト |
| ZAICO | 主要競合の在庫管理SaaS（スターター11,400円〜） |
