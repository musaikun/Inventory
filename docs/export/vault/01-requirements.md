# 01 要件定義

スナップショット: 2026-07-15 / v0.48（正: リポジトリ `docs/spec.md`）

## 背景・課題
飲食店の棚卸は月1〜2回・閉店後に紙とペンで2〜3時間。集計ミス・転記漏れ・複数端末のマージが属人化。

## 解決アプローチ
音声入力 → 辞書変換 → 在庫記録。複数端末リアルタイム同期で分担を即時合算。紙とペン・属人化からの脱却。

## 対象ユーザー
- 現場: 飲食店オーナー・店長・パート従業員（技術知識不要・スマホPWA）
- 買い手: 上層部（本部・オーナー）。有料価値は「削減額・ロス・人時・発注」の言語で語る

## 機能要件（コア）
| ID | 機能 |
|---|---|
| F-01 | 店舗登録・ログイン（店舗コード+PIN・複数端末） |
| F-02 | 品目リスト管理（PDF/CSV/Excel取込・品目マスタ） |
| F-03 | 棚卸セッション（開始・中断・再開・完了） |
| F-04 | 在庫入力（テキスト/音声/バーコード） |
| F-05 | 辞書補正（音声誤認識の正規化） |
| F-06 | リアルタイム同期（WebSocket/DO・競合解決） |
| F-07 | 変更履歴（auditLog: 誰が/いつ/何を） |
| F-08 | 完了スナップショット保存 |
| F-09 | 履歴閲覧・CSV出力 |
| F-10 | チャット |
| F-11 | 発注セッション・推奨発注数（v0.4x追加） |
| F-12 | 入出庫記録・理論在庫（v0.48追加） |
| F-13 | 分析ダッシュボード・履歴カレンダー（v0.4x追加） |

## 非機能要件（→ 詳細は [12 非機能要件](12-nonfunctional.md)）
音声遅延<500ms／同期反映<1秒／iPhone SE2以上／オフライン入力継続・再接続マージ／1店舗=1DOで分離。
