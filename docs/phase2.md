# Phase 2 — 分析機能仕様（将来）

## 計算式

```
実績使用量 = 期首在庫 + 仕入 - 期末在庫
理論使用量 = 商品販売数 × レシピ使用量
差分（ロス）= 実績使用量 - 理論使用量
ロス金額   = 差分 × 単価
原価率     = 理論原価 / 売上
```

分析軸: 食材別 / 週別 / 商品別
